# 1NSI

Cette section rassemble les cours de première NSI.

## Organisation des cours

Chaque chapitre peut contenir plusieurs leçons. Les élèves peuvent naviguer
entre les leçons grâce au menu latéral et aux boutons précédent/suivant.

## Exemple de parcours

1. Découvrir les notions essentielles.
2. Lire une leçon.
3. Réaliser les activités proposées.

Le premier chapitre est disponible dans la navigation latérale.
